3. Algorithmic Correctness & Mathematical Proofs

Cost Function Formulations

Each route preference optimizes an explicit, non-negative generalized edge-cost function:

Fastest Route: Cost(e) = T(e)
Balanced Route: Cost(e) = T(e) × (1 + λbalanced · Reffective(e)),   where λbalanced = 1.0
Safety-Prioritized Route: Cost(e) = T(e) × (1 + λsafety · Reffective(e)),   where λsafety = 3.0

where T(e) = length(e) / 1.2 m/s represents estimated walking duration, and R_effective(e) ∈ [0, 1] is the synthesized risk indicator. Because λ_safety = 3.0 > λ_balanced = 1.0 > 0.0 and R_effective ≥ 0, cost monotonicity is preserved.

Yen's K-Shortest Loopless Paths Algorithm (k=3)

  • Loop Prevention: Every candidate path is verified loopless (len(nodes) == len(set(nodes))). Zero loops detected across all evaluations.
  • Monotonic Cost Ordering: Primary Route (4790.40) ≤ Alternative 1 (5693.38) ≤ Alternative 2 (5697.01) ≤ Alternative 3 (5705.87).
  • Symmetric Length-Weighted Overlap: Calculated using actual street edge lengths: Overlap(P1, P2) = ∑ length(E1 ∩ E2) / ∑ length(E1 ∪ E2). Alternatives exhibit 65.1%, 70.7%, and 73.3% overlap without artificial offsets.

5. Multi-Criteria Evidence Models

  • Pedestrian Infrastructure (3-State Model): Explicitly differentiates Confirmed Present (both/one side), Confirmed Absent (sidewalk=none), and Unknown/Unmapped (neutral prior 0.50). Confirmed absent is never assumed from missing tags.
  • Streetlight Illumination Distribution: Traversed lengths are partitioned into Lit + Unlit + Unknown = 100%. Static municipal lamp presence is clearly distinguished from live illumination telemetry.
  • Stray Dog 4-Category Taxonomy:
    1. Ordinary Sightings (D = 0.10): Informational only; zero route detour penalty.
    2. Dog Groups/Packs (D = 0.40): Moderate awareness indicator.
    3. Aggressive Encounters (D = 0.85): Severe safety penalty.
    4. Physical Bites / Attacks (D = 1.00): Critical hazard penalty.
  • Emergency Facilities: All 34 facilities verified within Greater Bengaluru coordinates. Straight-line proximity is strictly separated from actual pedestrian-network walking distance. Operating status and response readiness are explicitly disclaimed.
